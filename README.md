# health-log

Локальный дневник давления. Монорепо pnpm: `apps/desktop` (Electron + React),
`packages/kernel`, `packages/contracts`, `packages/scales-data`.

(`docs/architecture/`), дорожная карта (`docs/roadmap/`), задачи (`docs/tasks/`).
