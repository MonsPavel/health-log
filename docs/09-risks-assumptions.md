## 2. Допущения (с обоснованием)

| ID | Допущение | Почему принято |
|---|---|---|
| A-1 | Первичная ОС — Windows 10/11 x64 | Целевая аудитория дневника давления на десктопе в РФ — Windows доминирует; владелец продукта работает на Windows; кроссплатформенность — желательна, не обязательна (OQ-1) |
| A-2 | В MVP — один дневник на устройство (без профилей) | Профили добавляют модели изоляции данных, но не входят в ядро ценности «вести свой дневник»; П4 переключает сценарий пост-MVP |
| A-3 | Единицы — мм рт. ст., аудитория — взрослые небеременные | Доминирующий стандарт бытовой тонометрии; особые группы требуют отдельных шкал — честнее предупредить (EC-11), чем сделать неправильно |
| A-4 | Измерения вводятся вручную с бытового тонометра (без Bluetooth) | Интеграция с устройствами — дорогой и хрупкий пласт (сертификация BLE-профилей, зоопарк моделей); ценность MVP не зависит от него |
| A-5 | Русский язык — первый и единственный в MVP | Владелец и первичная аудитория говорят по-русски; качественный перевод — отдельная работа, пост-MVP |
| A-6 | «Локальный ИИ» = LLM 3–4 млрд параметров в 4-битном квантовании, инференс на CPU/GPU устройства; однократная загрузка модели из интернета с явного согласия допустима | Это единственный класс моделей, который сегодня на целевом железе даёт связный русский текст; «скачать модель» не нарушает приватность — данные пользователя при этом не передаются |
| A-7 | Приложение бесплатное для личного использования; монетизация не в MVP | Владелец не заявлял монетизацию; подписки/реклама противоречат ценностному предложению приватности (OQ-3) |
| A-8 | Объём данных — до 50 000 записей (10+ лет) | Задаёт потолок требований к масштабу (NFR-9); больше — не целевой сценарий |
| A-9 | Offline-first; сеть только для обновлений и загрузки моделей по явному действию | Прямое следствие ценностного предложения; любое другое поведение — скрытый сетевой след |
| A-10 | Продукт позиционируется как не-медицинское изделие (wellness/self-tracking) | Ядро продукта — запись и описание данных; диагностика явно исключена (non-goals); риск и границы — R-1 |
| A-11 | Успех измеряется без телеметрии (опросы, скачивания, локальные индикаторы) | Телеметрия противоречит BG-2; выбор сделан в пользу доверия (OQ-10) |
| A-12 | Измерения делаются бытовым автоматическим тонометром (осциллометрическим) | Доминирующий тип домашних приборов; ртутные/механические — вне аудитор |

## 3. Открытые вопросы

Каждому вопросу дан **рабочий ответ по умолчанию** — спецификация написана так, будто он уже принят; смена ответа = ревизия SRS.

| ID | Вопрос | Рабочий ответ по умолчанию |
|---|---|---|
| OQ-1 | Только Windows или кроссплатформа с первого дня? | Windows 10/11 x64 — обязательно; macOS/Linux — «желательно, не блокирует MVP» |
| OQ-2 | Open source? Какая лицензия? | По умолчанию — исходники открыты (доверие в категории «здоровье+приватность» стоит дорого); лицензия — на выбор владельца |
| OQ-3 | Монетизация (бесплатно/донаты/платно)? | Бесплатно для личного использования; монетизация не в MVP |
| OQ-4 | Рантайм локального ИИ: сторонний (типа Ollama) или встроенный в приложение? Требование-рамка: пользователю не должны требоваться отдельные шаги установки сторонних инструментов | Встроенная интеграция без ручной установки сторонних программ; конкретика — предмет архитектуры, не SRS |
| OQ-5 | Минимальное железо для ИИ? | Рабочая цель: 8 ГБ RAM — минимально (маленькая модель), 16 ГБ — рекомендуется (Железо B); GPU не требуется |
| OQ-6 | Какой стандарт показывать основным — ESC/ESH (домашний порог ≥135/85) или AHA (≥130/80)? | ESC/ESH с примечанием о домашних порогах (табл. 4.1); выбор стандарта в настройках — пост-MVP |
| OQ-7 | Напоминания в MVP или пост-MVP? (Для П1 это критичная ценность.) | Пост-MVP, кандидат №1; в MVP — обучение привычке серией и пустыми состояниями. Готов пересмотреть в пользу MVP при ответе владельца |
| OQ-8 | Обязателен ли печатный формат сверх PDF? | PDF достаточно (печать через просмотрщик, FR-6.7) |
| OQ-9 | Формат SRS — по ГОСТ 34 / IEEE 830? | Структура следует логике IEEE 830, но без формальной бюрократии; переоформление — по требованию |
| OQ-10 | Принимаем ли A-11 (никакой телеметрии, включая опциональную)? | Да, без телеметрии; сбор отзывов — через репозиторий и опросы |
| OQ-11 | Включать ли приём лекарств (факт приёма, без доз) в MVP? | Нет — пост-MVP; заметка в тексте покрывает базовый сценарий |
| OQ-12 | Целевые страны распространения (для номеров экстренных служб, локалей, регуляторики)? | РФ в первую очередь; номера служб по локали |
