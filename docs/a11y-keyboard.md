# Клавиатурная ревизия потоков (TASK-108 §5, AC-7.3)

NFR-6 / AC-7.3: «пользователь использует только клавиатуру — доступны все основные
сценарии». Документ — чек-лист-матрица: каждый поток задан строкой «стартовая точка →
шаги → финиш» и таблицей клавиш; по нему идёт ручная ревизия (§19: клавиатурная матрица —
ручная по документу + один автоматизированный поток UC-01).

## Статус ревизии (честно)

- Пути потоков — **ревизия по коду** (указаны файлы-источники; DOM-порядок = порядок
  табуляции: положительных `tabIndex` в рендерере нет, из исключений — `tabIndex=-1`
  на `<main>` (цель skip-link) и стандартные фокус-ловушки Radix-диалогов).
- UC-01 автоматизирован — `apps/desktop/tests/e2e/a11y-keyboard.spec.ts`
  (tab-последовательность формы фиксирована ассертами в обе стороны; зелёный
  прогон — см. TASK-108).
- Ручные прогоны (человек за клавиатурой) — чек-боксы в разделе 10; на момент TASK-108
  **не отмечены** — отмечаются в PR (§20 AC3).

## 1. Общие соглашения (все потоки)

| Механика | Факт | Источник |
|---|---|---|
| Skip-link «Перейти к содержимому» | Первый Tab приложения; Enter → фокус в `<main>`; hash не меняется (HashRouter-safe) | `src-renderer/app/layout.tsx` (TASK-108) |
| Навигация | 5 ссылок (Динамика·Журнал·ИИ·Отчёты·Настройки); активная с `aria-current="page"` | `app/layout.tsx` |
| Видимый фокус | Глобальный `:focus-visible` — outline 2px `--hl-accent`, offset 2px; акцент темы контрастен фону (AA, `tokens.test.ts`) | `app/theme/theme.css` |
| Порядок табуляции | DOM-порядок; положительных `tabIndex` нет | ревизия рендерера |
| Диалоги | Radix Dialog/AlertDialog — фокус-ловушка, Esc, фокус-возврат; безопасное действие первым (первый Tab и «Enter-привычка» ведут к «Отмене») | `ConfirmFlagsDialog.tsx` §22 |
| Тосты/статусы | `role="status"`/`aria-live="polite"` — читаются без фокуса | компоненты (§16 каждой задачи) |

Ловушки табуляции вне диалогов отсутствуют; скролл-контейнер графика выведен из
`aria-hidden`-поддерева и не является таб-стопом (TASK-108, `TrendChart`/`PulseChart`).

Программно проверенные факты обхода (e2e UC-01, Chromium/Electron):

- Skip-link — первый Tab; Enter переносит фокус в `<main>`, hash не меняется.
- После смены маршрута/вида Chromium сохраняет точку последовательного обхода:
  Tab продолжает с места перехода (журнал → «Добавить»), фокус не сбрасывается
  в начало документа.
- Радио-пара руки — один таб-стоп (фокус на checked), ←/→ переключают значение,
  Tab уходит за всю группу.
- Disabled-кнопки (например «Сохранить» пустой формы) не являются таб-стопами —
  последовательность «сжимается» честно.

## 2. Поток «Ввод измерения» (UC-01, автоматизирован)

**Старт** → «Динамика» (стартовый маршрут) → **шаги** → **финиш**: запись «Сегодня» в
истории, вид «Журнал».

1. Tab → skip-link → Enter (фокус в контент).
2. Tab до ссылки «Журнал» → Enter; пустая БД — CTA «Добавить измерение» пустого
   состояния, с данными — кнопка «Добавить» в шапке (Enter) → форма «Новое измерение» (h1).
3. Порядок табуляции формы (`MeasurementForm.tsx`, DOM-порядок):
   поле СДА → ДДА → ЧСС (readonly-поля: цифры с основной клавиатуры, после 3-й цифры
   автопереход в следующее; `Backspace`; Enter на ЧСС = сохранить — UC-01) →
   чекбокс «Неровный пульс» (Space) → рука «Левая/Правая» (native radio, ←/→ —
   один таб-стоп на группу) → «Заметка» (textarea) → «Дата», «Время»
   (native-инпуты; кнопка «Сейчас»/«Изменить») → «Сохранить» (disabled на
   невалидной форме — не таб-стоп) → «Отмена» → «Очистить» → DigitPad
   (кнопки «Ввести N», «⌫», «C» — aria-label).
   Форма ставит автофокус в СДА при открытии (§5); может открыться с
   восстановленным черновиком (TASK-039) — «Очистить» сбрасывает его с клавиатуры.
4. Критические значения (125/82 и др.) открывают ConfirmFlagsDialog (Radix Dialog):
   первый фокус — безопасное «Отмена»; Esc — возврат к форме, запись не создана.
5. Esc на форме (вне диалогов) — отмена, возврат к списку.
6. Успех — тост «Сохранено» (`role="status"`), список обновлён.

Критерий AC-7.3 (ввод) покрыт e2e: `tests/e2e/a11y-keyboard.spec.ts` — фиксированная
tab-последовательность + сохранение только клавишами.

## 3. Поток «История + фильтры»

**Старт** → «Журнал», вид списка → **шаги** → **финиш**: отфильтрованный список /
правка / удаление, фокус возвращён в строку.

- Фильтры (`HistoryFilters.tsx`): период — native radio в fieldset (←/→, Tab на
  следующую группу); «Рука» — native select (↑/↓, Enter); «Только с заметками» —
  checkbox (Space); поиск — `type="search"`: Esc очищает, кнопка ×  с aria-label;
  произвольный период — дата-инпуты (invalid блокируется внутри `CustomRangeFields`);
  кнопка «Сбросить».
- Строки списка: текст строки не таб-стоп; таб-стоп строки один — кнопка «⋮»
  (aria-label «Действия с записью»). Enter/Space → меню (Radix DropdownMenu):
  ↑/↓ — «Изменить»/«Удалить», Esc/Tab — закрытие с возвратом фокуса на «⋮» (Radix).
- «Изменить» → форма «Изменение записи»; Esc/«Отмена» — возврат к списку, фокус —
  в строку-источник (`HistoryScreen.tsx` §20 AC5).
- «Удалить» → DeleteConfirmDialog (Radix AlertDialog): фокус-ловушка, первый фокус —
  «Отмена» (безопасный дефолт), Esc — запись на месте; подтверждение — удаление,
  тост «Удалено», фокус в ближайшую оставшуюся строку.
- «Показать ещё» — кнопка пагинации; «Показано N из M» — текст.

## 4. Поток «Динамика»

**Старт** → «Динамика» → **шаги** → **финиш**: период/вид переключены, таблица
отсортирована — всё клавиатурой.

- Период 7д/30д/90д/всё/произвольный — native radio-сегмент в fieldset/legend
  (`PeriodSwitcher.tsx`, ←/→); «Произвольный» раскрывает поля дат.
- «Давление/Пульс» и «График/Таблица» — кнопки с `aria-pressed`
  (`DashboardScreen.tsx` §10 058) — Tab + Enter.
- График сознательно не таб-стоп: резюме графика — `aria-label` фигуры (`role="img"`,
  TASK-057/059); точечные тултипы — мышь. Клавиатурная альтернатива — режим
  «Таблица» (`?as=table`): caption, `th scope`, сортировка — кнопки в заголовках с
  `aria-sort` (`TrendTable.tsx` §16 059).
- Карточки сводки: «Добавить измерение» — CTA на форму.

## 5. Поток «ИИ»

**Старт** → «ИИ» → **шаги** → **финиш**: резюме/вопрос-ответ/выбор модели — без мыши.

- Вкладки «Разбор/Чат/Модель» — кнопки с `aria-pressed` (решение §10 058 — не
  tablist), Tab + Enter, состояние в URL `?tab=` (`AiPage.tsx`).
- Баннер онбординга: кнопка «Настроить позже» (не модальный, `role="status"`).
- «Разбор» (`InsightScreen.tsx`): контролы параметров — нативные; «Сгенерировать» —
  кнопка (`aria-busy` при генерации), «Остановить» во время генерации; предпросмотр
  контекста — `role="note"`.
- «Чат» (`ChatScreen.tsx` §5): textarea — Enter = отправить, Shift+Enter = перенос,
  IME-композиция не отправляет; кнопка отправки disabled при пустом вводе; при
  стриме ввод disabled + кнопка «Остановить»; лента — `role="log"`
  `aria-live="polite"`; «Очистить чат» — с подтверждением (диалог).
- «Модель» (`ModelCard.tsx`): кнопки «Скачать»/«Выбрать»/«Удалить» — `aria-busy`/
  disabled на время операций (BUSY-превенция UI+сервер).

## 6. Поток «Отчёты»

**Старт** → «Отчёты» → **шаги** → **финиш**: CSV/JSON/PDF сохранены.

- «Экспорт CSV»/«Экспорт JSON» — кнопки (`aria-busy` на время сборки) → нативный
  save-диалог ОС (обычный оконный фокус, не часть DOM-табуляции); после — тост
  `role="status"` с именем файла (`ExportButtons.tsx`).
- PDF (`ReportBuilder.tsx`): даты «от/до» — native date-инпуты, «Собрать PDF» —
  кнопка (`aria-busy`, честная оценка времени), статусы — `role="status"`.

## 7. Поток «Копии» (секция «Данные» на «Отчётах»)

**Старт** → «Отчёты» → секция «Данные» → **шаги** → **финиш**: копия создана /
восстановлена / отказ — безопасно.

- «Создать копию» → BackupDialog (Radix AlertDialog): пароль ×2 (password-поля),
  обязательный чекбокс-предупреждение «Забыли пароль — копию не восстановить»
  (Space; без галочки подтверждение недоступно), «Отмена»/Esc — безопасный дефолт,
  фокус-ловушка; подтверждение → нативный save-диалог → тост с именем файла
  (`BackupDialog.tsx` §13/§14).
- «Восстановить из копии» → RestoreFlow (AlertDialog: путь файла через нативный
  open-диалог, пароль, предупреждение о замене БД; Esc — отказ).
- «Удалить всё» → WipeFlow (AlertDialog: «необратимо» + подтверждение; Esc — отказ).

## 8. Поток «Настройки»

**Старт** → «Настройки» → **шаги** → **финиш**: любая настройка применена
(мгновенно/по кнопке), диалоги — с безопасным Esc.

- «Простой режим» — `role="switch"` кнопка (Space/Enter) с `aria-labelledby`.
- «Вид» (`AppearanceSection.tsx`): Тема и Размер текста — native radio (←/→);
  контролы disabled, пока prefs не загружены.
- «Защита паролем» (`SecuritySettings.tsx`): «Включить» → PassphraseDialog
  (AlertDialog: пароль ×2 + обязательный чекбокс-предупреждение о
  невосстановимости; Esc — отмена); на включённой защите — «Сменить», «Снять»,
  автоблок — native select (↑/↓).
- «Обновления» (`UpdatesSection.tsx`): «Проверить»/«Скачать»/«Установить» — кнопки с
  `aria-busy`; статусы — `role="status"`/`role="alert"`.
- «Приватность» (`PrivacyScreen.tsx`): самопроверка — кнопка-аккордеон
  (`aria-expanded`/`aria-controls`); операции/согласия — кнопки и switch с диалогами.
- «О приложении» (`AboutSection.tsx`): «Полная проверка БД» — кнопка (`aria-busy`);
  статус — `role="status"` (текст + глиф, не только цветом).
- «Диагностика» (`DiagSection.tsx`): «Предпросмотр»/«Сохранить» — кнопки; save →
  нативный диалог; golden-предупреждение — `role="note"`.
- Секция «Продвинутые» — в DOM только при включённом продвинутом режиме.

## 9. Поток «Блокировка»

**Старт** → locked (старт в режиме пароля или `lock:engaged`) → **шаги** → **финиш**:
разблокировка, маршруты монтируются.

- Фокус сразу в поле пароля (`autoFocus`, `LockOverlay.tsx`); ввод; Enter =
  «Разблокировать» (submit). Таб-стопов ровно два: поле и кнопка — под оверлеем
  контента в DOM нет (маршруты не монтируются, §14 095), уйти по Tab наружу
  невозможно и не нужно: ловушка = весь UI.
- «Проверка…» — `aria-busy` на кнопке; ошибка «Неверный пароль» — `role="alert"` +
  `aria-invalid` + `aria-describedby`, фокус возврат в поле.
- Окно backoff: кнопка disabled, «Подождите N с» — `aria-live="polite"` (`role="status"`).
- Esc без действия — безопасного пути нет, блок обязателен (§16 095).

## 10. Чек-лист ручного прогона (человек, клавиатура; отметить в PR)

- [ ] Ввод (UC-01): полный путь от старта приложения до «Сохранено» без мыши.
- [ ] История+фильтры: период/рука/заметки/поиск/сброс; меню строки; правка и
      удаление с возвратом фокуса.
- [ ] Динамика: период, вид, «Таблица», сортировка.
- [ ] ИИ: вкладки, генерация резюме, чат (Enter/Shift+Enter/стоп), модель.
- [ ] Отчёты: CSV, JSON, PDF — до нативного диалога ОС.
- [ ] Копии: создание (с чекбоксом-предупреждением), восстановление, отказ по Esc.
- [ ] Настройки: switch, темы/масштаб, защита паролем (вкл/смена/снятие), обновления,
      приватность, о приложении, диагностика.
- [ ] Блокировка: неверный пароль → ошибка и фокус в поле; верный → разблокировка;
      backoff-отсчёт озвучивается/виден.
- [ ] Видимый фокус различим на обоих темах и трёх масштабах; ловушек вне диалогов нет.
