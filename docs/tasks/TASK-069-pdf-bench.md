## 2. Цель

Bench-скрипт: генерация 5k записей в tmp-БД → полный путь report/pdf (рендер в пуле, сохранение во tmp) → замер → гейт ≤30 с (NFR-4); отчёт JSON+текст; скрипт `bench:pdf`.

## 3. Бизнес-контекст

PDF — самая тяжёлая регулярная операция; гейт защищает от тихой деградации шаблона/библиотеки (обновления @react-pdf/renderer). Базовая линия для TASK-111.

- **Архитектура:** perf-скрипты — арх. 10 §1; паттерн — как TASK-062 (HL_BENCH-каналы, tmp-изоляция).
- **Обоснование:** полный путь (не только рендер): собираем данные как use case —bench мерит пользовательский опыт.
