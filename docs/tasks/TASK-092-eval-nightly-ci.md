## 2. Цель

Workflow `eval-nightly.yml`: по расписанию (ночью) и вручную — eval на компактной модели (~1B, кэшируемой артефактом) на ubuntu-runner; отчёт — артефакт прогона; статус НЕ блокирует PR (отдельный ночной контур, TD-7).

## 3. Бизнес-контекст

Регулярный пульс guardrails: деградация от обновления зависимостей (node-llama-cpp, политики) ловится за сутки. Полный гейт на релизе — ручной прогон на полной модели (TASK-105), ночь — дешёвый детектор.

## 4. Технический контекст

- **Архитектура:** CI-каркас TASK-014; сегрегация от PR — осознанная (стоимость модели, TD-7).
- **Обоснование:** 1B-модель (~700 МБ) кэшируется actions/cache по ключу версии из манифеста; ubuntu-runner достаточен (CPU-инференс headless — UtilityProcess работает без дисплея; xvfb не нужен — окно не создаётся в eval-режиме? eval запускает контейнер без окна: параметр headless контейнера — включить в 091? УТОЧНЕНИЕ: eval использует use case'ы напрямую без BrowserWindow — Electron app stub (`app.whenReady` без окна) — деталь реализуется здесь через флаг env `HL_EVAL_HEADLESS=1` в bootstrap: не создавать окно. Включить в объём).

## 5. Объём

- **Включено:** `eval-nightly.yml`: schedule cron (03:00 UTC) + workflow_dispatch; шаги: checkout → pnpm → build → кэш модели (путь `~/.hl-eval-model`, ключ `model-1b-v1`) → если кэша нет: скрипт скачивает dev-модель из манифеста через curl (открытый URL, sha256-проверка тем же скриптом) → `pnpm eval -- --model <path> --report out` → upload артефакта отчёта; статус в Security-таб? НЕТ: отдельный check — зелёный/красный по гейту 100%; README-бейдж? (опционально — нет); headless-флаг в bootstrap (§4).
- **Не включено:** полную модель (мануально), уведомления в мессенджеры (вне MVP), автогейт PR.
- **Будущая работа:** комментировать коммит при деградации (post-MVP инфраструктура).

## 6. Файлы

- **Создать:** `.github/workflows/eval-nightly.yml`; `tools/scripts/fetch-eval-model.mjs` (скачивание+sha256, переиспользует манифест).
- **Изменить:** `main/app/bootstrap.ts` (env `HL_EVAL_HEADLESS=1` → контейнер без BrowserWindow — маленький патч; тест-флаг).
