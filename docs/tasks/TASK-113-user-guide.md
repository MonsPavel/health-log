## 2. Цель

`docs/user/`: руководство новичка — установка и первый запуск, ежедневный цикл дневника, настройка локального ИИ, копии и восстановление, приватность (что где и как проверить), границы продукта («это не медицинский совет»), FAQ (забыл пароль, переезд на новый ПК, пропуски измерений).

## 3. Бизнес-контекст

Сценарии поддержки без разработчика: П1 должна сама пройти путь (критерий успеха BG-1), Анна — восстановить мамин дневник; раздел «границы» — повторение юридической рамки в человеческих словах (R-7).

## 4. Технический контекст

- **Архитектура:** N/A — документ; язык простой (NFR-6-дух: без жаргона, термины поясняются).
- **Обоснование:** markdown в репо (+линк из приложения «Помощь» — экран настроек, гиперссылка на файл/репозиторий — точка интеграции включена минимально: канал `app/open-docs` — открытие docs/user в браузере/проводнике).

## 5. Объём

- **Включено:** страницы: (1) `install.md` — установка, первый запуск, включение пароля/крупного текста (персональные сценарии П3: «настройте сразу»); (2) `daily.md` — измерение, ввод, история, фильтры, динамика (со скриншотами — на фикстурных данных, синтетика); (3) `ai.md` — что делает ИИ и чего не делает, настройка модели (скачивание, место), примеры вопросов, отказы — почему; (4) `data.md` — копии (пароль копии!), восстановление, переезд на новый ПК, полное удаление; (5) `privacy.md` — где смотреть сетевую активность, как проверить самому; (6) `faq.md` — забыл пароль приложения/копии, пропустил измерения (без вины, FR-4.4), что делать при 190/120 (панель+103), нашёл баг (диагпакет 103); (7) `index.md` — оглавление+линк из настроек; e2e-мини: проверка «новичок по документу» (ручная — §24).
- **Не включено:** видео (пост-MVP), EN-версию (TD-4).
- **Будущая работа:** контекстная справка в UI (пост-MVP).

## 6. Файлы

- **Создать:** `docs/user/{index.md,install.md,daily.md,ai.md,data.md,privacy.md,faq.md}` (+скриншоты `docs/user/img/*`); канал `app/open-docs {page}` + хендлер (shell.openExternal на путь репо/docs — локальный файл через shell.openPath).
- **Изменить:** `SettingsScreen` (ссылка «Помощь»), ключи i18n.
