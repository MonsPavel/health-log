## 2. Цель

Чат поверх данных: `AskChat {question, period}` — префильтр 086 → контекст периода (083) + последние N сообщений истории → генерация со стримом → ResponseGuard → сохранение пары вопрос/ответ (миграция **v7** chat_message); `ClearChat` — необратимая очистка истории.

## 3. Бизнес-контекст

US-19: вопросы своими словами («почему вечером выше?») с опорой на данные — режим для П2. Guardrails те же (AC-5.1 в чате — обязательные проверки 089-тестов). История локальна и очищаема (UC-04).

## 4. Технический контекст

- **Архитектура:** чат-контекст — арх. 07 §5 (короткая генерация с контекстом периода); миграция v7.
- **Обоснование:** контекст периода включается в КАЖДЫЙ вопрос (не длинная тянущаяся сессия): ответы всегда привязаны к данным; история — только для связности последних ходов (последние 6 сообщений — константа CHAT_HISTORY_DEPTH=6).

## 5. Объём

- **Включено:** миграция **v7** `chat_message (id, profile_id, role 'user'|'assistant', content, refusal_class NULL, created_at_utc)` + индекс; порт `ChatRepository` + адаптер (append, listRecent(6), clearAll); use cases: `AskChat`: BUSY-гвардия (общая с резюме — одна генерация на приложение) → префильтр 086 (классификация вопроса; refusal → сохранить user+assistant-отказ с refusal_class, БЕЗ LLM — история ведётся честно) → контекст (кэш по hash периода — переиспользование сборки) → history 6 → генерация (systemPrompt чат-вариант: та же политика + строка «это диалог, отвечай на последний вопрос с учётом истории») → guard → дисклеймер-футер ответа (краткий) → append обоих; события ai:token переиспользуются; `ClearChat` → deleteAll; каналы: `ai/chat/send {question, period} → {requestId}` + `ai/chat/result {requestId, messageId}`, `ai/chat/clear {} → {cleared}`, `ai/chat/list {limit} → {messages}` (для UI-инициализации); тесты.
- **Не включено:** сессии/темы (одна плоская история — решение), markdown/ссылки на записи в ответах (текст; ссылки — пост-MVP).
- **Будущая работа:** экспорт диалога; интерактивные ссылки на записи (post-MVP P5-полировка).
