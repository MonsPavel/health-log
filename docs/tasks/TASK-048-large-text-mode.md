## 2. Цель

Переключатель размера текста (обычный/крупный/очень крупный — классы масштаба на `<html>`, токены из TASK-013) подключён к prefs; все основные экраны верифицированы на всех трёх масштабах: ничего не обрезается и не перекрывается (AC-7.2).

## 3. Бизнес-контекст

П3 (68 лет, слабое зрение) — полноправная персона: «крупный режим» — не украшение, а условие использования (NFR-6). Проверка вёрстки на масштабах — обязательный ритуал каждой фичи начиная с этой задачи.

## 4. Технический контекст

- **Архитектура:** токены rem — TASK-013 §5; prefs — TASK-047.
- **Обоснование:** rem-масштабирование (font-size на `<html>`) масштабирует весь rem- UI; фиксированные px-высоты — источник брейков, поэтому эта задача включает ревизию существующих компонентов на предмет px-высот (аудит + правки).

## 5. Объём

- **Включено:** секция «Размер текста» в настройках (сегмент 3 опций → prefs.textScale); применение: класс `scale-100/112/125` на `<html>` → CSS `html.scale-112 {font-size:112.5%}` и т.д.; аудит-правки существующих экранов (journal, dashboard, settings, диалоги): высоты-минимумы вместо фикс-высот, перенос длинных строк, обрезание ellipsis только с title; E2E-снапшот-тесты: ключевые экраны × 3 масштаба × 2 темы (visual-screenshots, порог диффа; базлайны коммитятся); юнит-тест масштаб-классов (ThemeProvider).
- **Не включено:** масштаб только шрифтов без лейаута (не делаем — целое rem-дерево), пользовательский произвольный % (три пресета — решение SRS FR-8.2).
- **Будущая работа:** компактный режим (обратный) — не планируется.

## 6. Файлы

- **Создать:** `theme/scale.css` (классы масштаба); e2e-спека `visual-scales.spec.ts` (+ baseline-снапшоты `tests/e2e/__screenshots__`); правки компонентов по аудиту.
- **Изменить:** `SettingsScreen` (секция), `ThemeProvider` (класс из prefs), компоненты по аудиту (перечислить в PR: ожидаемо MeasurementRow, Dialog-компоненты).

## 13. Бизнес-логика

Правила вёрстки (чек-лист аудита, фиксируется в PR-описании): (1) ни одного фикс. px-высот у контейнеров текста — min-height; (2) кнопки — padding-based, не height; (3) таблицы/строки — перенос, не обрезка; (4) модальные диалоги — max-height с внутренним scroll; (5) цифры формы (TASK-031) — масштабируются, кнопки остаются ≥44px (растут).
