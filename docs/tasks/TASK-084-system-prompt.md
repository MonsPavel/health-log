## 2. Цель

Сборщик system prompt из GuardrailPolicy: роль ассистента дневника, явные запреты (диагнозы/дозы/лечение), обязательства (дисклеймер, период, разрывы, тон), правило малых данных; версия шаблона `PROMPT_TEMPLATE_VERSION` участвует в contextHash.

## 3. Бизнес-контекст

Первый эшелон guardrails (арх. 07 §4): промпт — «мягкий» контроль, задающий тон и рамки; жёсткие гарантии дают префильтр (086) и пост-фильтр (085). Шаблон версионируется: смена = новые contextHash = честные бейджи устаревания резюме.

## 4. Технический контекст

- **Архитектура:** шаблон — арх. 07 §4 эшелон 1; hash — 083.
- **Обоснование:** шаблон собирается из секций политики (запреты — из policy.refusals descriptions), а не одной строкой: читаемо, тестируемо по секциям. RU-язык (FR-5.9): prompt на русском — модель выбирается русскоязычной (081).

## 5. Объём

- **Включено:** `buildSystemPrompt(policy, contextMeta): string` — секции: РОЛЬ («Ты — помощник для разбора дневника давления пользователя. Ты работаешь только с данными, которые даны ниже»); ЧТО ДЕЛАТЬ (описывай данные, тренды, различия утро/вечер, упоминай разрывы; отделяй «что видно в данных» от «что это может значить»); ЧТО ЗАПРЕЩЕНО (по классам политики: не ставь диагнозы; не советуй начинать/менять/прекращать лекарства и дозы; на вопросы о лечении — отказ и совет обратиться к врачу); ОБЯЗАТЕЛЬНО (в конце — пометка «Это не медицинская консультация»; укажи анализируемый период; при разрывах — назови их явно); МАЛО ДАННЫХ (если данных < порога — не обобщай, скажи прямо); ТОН (спокойный, простой язык, без паники и терминов без пояснений); `PROMPT_TEMPLATE_VERSION = '1'` (константа, экспорт, коммент-синхронизация с 083-hash); снапшот-тест собранного промпта; тест секций (каждый класс запретов присутствует).
- **Не включено:** few-shot примеры (пост-MVP по качеству eval), EN-версию.
- **Будущая работа:** итерация текста по eval-результатам (091) — бамп версии обязателен при смене.

## 13. Бизнес-логика

Собранный промпт обязан содержать (тесты): строку запрета доз; «не медицинская консультация»; фразу о разрывах при hasGaps; фразу отказа от обобщений при insufficientData; упоминание периода (подстановка).
