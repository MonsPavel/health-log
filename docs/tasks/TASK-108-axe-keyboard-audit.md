## 2. Цель

Полный axe-прогон (все маршруты × 2 темы × 3 масштаба) с исправлением critical/serious; клавиатурная ревизия всех пользовательских потоков (ввод, история+фильтры, динамика, ИИ, отчёты, копии, настройки, блокировка) — достижение и фиксация AC-7.3.

## 3. Бизнес-контекст

NFR-6: доступность — профиль ядра аудитории (П3), не комплаенс-галочка. Задача — последний общий проход до релиза: собирает накопленные мелкие нарушения в системные правки.

## 4. Технический контекст

- **Архитектура:** NFR-6, WCAG 2.1 AA — целевые уровни; axe-core в e2e (появился с TASK-035+фич).
- **Обоснование:** полный прогон именно в P7: до этого — фичевые прогонки; системные паттерны нарушений правятся один раз (токены/компоненты), не точечно.

## 5. Объём

- **Включено:** e2e-спека `a11y-full.spec.ts`: все 7 маршрутов × матрица (2 темы × 3 масштаба) → axe.run → критерий: 0 critical, 0 serious violations (moderate/minor — реестр с обоснованием отложенных, docs/a11y-реестр); исправления типовых находок (ожидаемые классы: контраст вторичных текстов, заголовки-иерархии, aria-лейблы иконочных кнопок, фокус-видимость); клавиатурная ревизия: чек-лист-документ `docs/a11y-keyboard.md` — по каждому потоку: полный путь Tab/Shift+Tab/Enter/Esc/стрелки (где применимо — меню/сегменты), видимый фокус, ловушки отсутствуют; найденные дыры — правки (напр., skip-link «к содержимому» при необходимости, порядок табуляции диалогов); e2e-проверка потока ввода только с клавиатуры (автоматизировать UC-01: tab-последовательность фиксирована).
- **Не включено:** NVDA (109), скринридер-автоматизация (недостоверна — решение).
- **Будущая работа:** axe в каждый PR (правило DoD уже — «axe на экране фичи»); инкрементальные аудиты.
