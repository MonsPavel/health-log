## 2. Цель

`AiContextBuilder.build(period, options) → AiContext`: детерминированная текстовая проекция данных периода (агрегаты, серии по дням, разрывы, пометки, заметки — опционально) + `contextHash = SHA-256(period, опции, content, modelId, PROMPT_TEMPLATE_VERSION)`; одинаковый вход = байт-одинаковый контекст.

## 3. Бизнес-контекст

ИИ получает проекцию, а не прямой доступ к БД (арх. 07 §3): кэш резюме (FR-5.7), прозрачность «какие данные переданы» (FR-5.5) и воспроизводимость eval (091) стоят на этом хеше. RAG/векторные базы не нужны: период помещается в контекст целиком.

## 4. Технический контекст

- **Архитектура:** AiContext — арх. 02 §3.3; сборка кодом, не LLM — 07 §3.
- **Модуль:** `ai-insight/application`.
- **Обоснование:** формат проекции — компактный markdown-подобный текст (LLM-дружелюбный, читаемый человеком в превью FR-5.5): секции `# Период`, `## Агрегаты`, `## По дням`, `## Разрывы`, `## Заметки`, `## Шкала`. Детерминизм: сортировки по фиксированным ключам, округления по правилам, никаких дат «сейчас» внутри (только сам период).

## 5. Объём

- **Включено:** `AiContextBuilder`: вход `{profileId, period, includeNotes, modelId}`; сборка: stats (054 read model), серии (056), разрывы ≥7 дней (сканирование дат), пометки критических/irregular в сериях, заметки (текстом, если includeNotes), шкала (051); лимит объёма: если raw-точек > 90-дневного эквивалента (константа CONTEXT_MAX_DAYS=90) → агрегированные серии + пометка «данные агрегированы» (защита контекст-окна); `contextHash` = SHA-256(canonical-строка: period-json + опции + полный текст + modelId + PROMPT_TEMPLATE_VERSION-placeholder (заполняется в 084 — константа HERE = 'v1-template' с комментарием синхронизации)); юнит-тесты детерминизма (байт-равенство при перестановках входных записей!), тесты разрывов, excludeNotes.
- **Не включено:** сам шаблон промпта (084), вызовы LLM.
- **Будущая работа:** сжатие серий при очень длинных периодах (квартальные агрегаты).

## 13. Бизнес-логика

Детерминизм-инварианты (property-тесты): перестановка порядка записей → идентичный text; одинаковые периоды в разные дни календаря (период задан абсолютными датами) → идентичный hash; включение/выключение заметок меняет hash и наличие секции. Разрывы: ≥7 дней без записей между датами периода; формат «03.07–17.07 (14 дней)».

## 14. Безопасность

Заметки включаются ТОЛЬКО при includeNotes (тест: без опции — ни байта заметок); текст контекста не логируется (PHI).
