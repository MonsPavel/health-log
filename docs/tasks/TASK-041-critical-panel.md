## 2. Цель

Полноценная панель срочной помощи при сохранении критического значения: точный текст SRS FR-7.4, перечень симптомов, локализованные номера экстренных служб (в РФ: 103/112), тон «спокойный факт, не паника», без диагнозов, без блокировки ввода.

## 3. Бизнес-контекст

Duty-of-care: молчание приложения при 200/130 недопустимо этически; «вызываем скорую за вас» — уже медизделие (R-1). Панель — центральный элемент доверия и ответственности продукта (UC-06, AC-6).

## 4. Технический контекст

- **Архитектура:** FR-7.4; триггер — политика TASK-020 (флаг из ответа add/update).
- **Пакет:** renderer `components/critical-panel`.
- **Обоснование:** отдельный компонент (не часть диалога TASK-032): переиспользуется в диалоге ввода, в истории (просмотр записи) и в статистике (P3); реестр номеров служб — данные по локали, не хардкод.

## 5. Объём

- **Включено:** компонент `CriticalPanel {flag: 'high'|'low', onDismiss}`: для high — полный текст: «Давление {sys}/{dia} может указывать на гипертонический криз…» (точная формулировка SRS 04 FR-7.4), список симптомов (сильная головная боль, боль в груди, одышка, нарушение речи или зрения), призыв «немедленно обратитесь за медицинской помощью», номера по локали (RU: «103 (скорая), 112 (единый)»); для low — мягкий вариант: «давление ниже типичных значений; при слабости/головокружении обсудите с врачом»; реестр `EMERGENCY_NUMBERS: Record<locale, {primary: string, unified?: string}>` (ru — 103/112; en-US — 911; fallback — «номер местной службы экстренной помощи»); интеграция: диалог TASK-032 заменяет сокращённый блок на этот компонент; просмотр записи с критическим значением в истории (TASK-042 место) — кнопка/блок; тесты.
- **Не включено:** попытки «дозвониться»/deep-link tel: — НЕТ (пользователь звонит сам; tel-ссылка допустима? Решение: НЕТ в MVP — десктоп без телефона; просто текст), пуш-повторные напоминания о значении.
- **Будущая работа:** номера по стране ОС-локали (сейчас — язык интерфейса).
