## 2. Цель

`pnpm dist` собирает установщик (NSIS) и распакованную сборку Windows; собранное приложение устанавливается, запускается и полноценно работает с зашифрованной БД в userData; нативный модуль (SQLCipher) внутри сборки.

## 3. Бизнес-контекст

«Работает только в dev» — самый дорогой вид долга (дорожная карта P1.4): проблемы ASAR-путей, ABI нативного модуля, userData-путей вскрываются сейчас, а не через 10 фич. Доверие пользователя начинается с двойного клика по установщику.

## 4. Технический контекст

- **Архитектура:** развёртывание — `docs/architecture/10-delivery.md` §2; бюджет размера — NFR-5/D1a.
- **Инфраструктура:** electron-builder, NSIS target, x64.
- **Обоснование:** NSIS (не msi/portable) — стандарт, автообновление electron-updater совместимо (TASK-096/104). Portable — post-MVP (C).

## 5. Объём

- **Включено:** `electron-builder.yml`: appId `dev.healthlog.app`, productName `Health Log`, win target nsis (x64), asar on, files: `dist-main`, `dist-renderer`, `node_modules` (только prod-зависимости; нативный `.node` — asarUnpack), extraResources (пока пусто, реестр моделей позже), nsis: one-click=false, allowToChangeInstallationDirectory=true, perMachine=false (per-user — не требует админа); иконки-заглушки (dev-иконка, бренд — post-MVP); скрипт `dist` = build main+renderer → builder; локальная проверка: установка, запуск, полный цикл ввода.
- **Не включено:** подпись (TASK-104), автообновление (TASK-096), CI-сборка (TASK-105), иконки бренда.
- **Будущая работа:** macOS/Linux targets (пост-MVP).

## 6. Файлы

- **Создать:** `apps/desktop/electron-builder.yml`, `apps/desktop/build/icon-dev.ico` (заглушка), скрипты.
- **Изменить:** `apps/desktop/package.json` (скрипты dist, build-порядок main+renderer), `vite.config.ts` (base пути для file://).

## 20. Критерии приёмки

- [ ] `pnpm dist` создаёт `Health Log Setup <version>.exe` и win-unpacked без ошибок.
- [ ] Установка per-user без прав администратора; запуск с ярлыка работает.
- [ ] Полный цикл в packaged: ввод измерения → в истории; перезапуск → данные на месте (зашифрованная БД персистентна).
- [ ] Файл БД в `%APPDATA%/health-log/` нечитаем текстовым редактором (шифрование в packaged).
- [ ] Установщик ≤200 МБ (первичный замер; гейт — TASK-036).
- [ ] Логи пишутся в userData/logs и не содержат debug-шума (packaged-уровень).
