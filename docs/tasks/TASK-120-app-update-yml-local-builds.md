## 2. Цель

electron-builder генерирует `resources/app-update.yml` только в
publish-manager-пути (на теге в CI он активируется неявно — stable.yml в draft
прогона 9 это подтверждает). Локальные no-tag сборки (`electron-builder --dir
--publish never`) файл не получают → `updater-unavailable`/ошибки обновлятора,
S3-сценарий сетевого аудита невоспроизводим локально (в аудите 2026-Q1 файл
писался вручную). Решение — детерминированная догенерация из publish-блока
конфига.

## 3. Объём

- **Включено:** послеPack-хук (или скрипт, вызываемый рядом со сборкой в
  документации): если `publish` настроен, а `resources/app-update.yml`
  отсутствует — записать его (provider/url/channel/publisherName из
  electron-builder.yml); юнит-тест генератора (чистая функция: конфиг → yaml);
  обновить `docs/dev/certificates.md`/CONTRIBUTING §11 (локальная сборка для
  аудита: файл появляется сам).
- **Не включено:** изменение CI-pipeline (там файл и так есть); публикация.

## 4. Критерии приёмки

- [ ] Юнит: генератор из конфига даёт yaml, совпадающий с ручным образцом аудита (provider generic, url latest/download, channel stable, publisherName).
- [ ] Локальная сборка `--dir --publish never` содержит `resources/app-update.yml`.
- [ ] Полный gate зелёный.

## 5. Проверка

Автоматически (юнит + локальная сборка в приёмке). Откат: revert хука.
