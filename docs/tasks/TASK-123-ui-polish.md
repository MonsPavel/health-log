## 2. Цель

Дизайн-план «Тихий тонометр» (предметная область: спокойный медицинский
инструмент + бумажный дневник для 55+): палитра перестаёт быть серой — глубокий
клинический teal как единственный голос интерактива; иерархия через слои
(bg → surface + одна мягкая тень) вместо рамок; табличные цифры показаний.
Одновременно закрываются KI-3/KI-4: ВСЕ цветовые решения — через токены
(классы `dark:` запрещены — они следуют prefers-color-scheme ОС, а не теме
приложения), границы полей ≥3:1, вторичный текст ≥4.5:1 в обеих темах.

## 3. Объём

- **Включено:** tokens.css — новая палитра обеих тем + 4 новых токена (surface,
  muted, input-border, status-warn); theme.css — мост @theme, тень shadow-e1,
  класс hl-nums, motion-safe переходы 120 мс на отклик действия; sweep 28
  файлов рендерера: `dark:`/`neutral`/`amber`/`red` → токены; контраст-реестр
  расширен (6 новых пар, из них 4 гейт-пары 4.5:1); визуальные базлайны
  перегенерированы (30); навигация — surface + rounded-lg.
- **Не включено:** смена шрифтов (системный стек — осознанно для 55+), редизайн
  компоновки экранов (ИА неизменна), анимации появления.
