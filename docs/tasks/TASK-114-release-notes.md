## 2. Цель

Шаблон release notes (`.github/release-template.md`) + процесс заполнения на релизе: разделы Фичи/Исправления/Известные проблемы + обязательные строки версий (приложение, схема БД, справочная шкала, ИИ-модель, ссылка на сетевой аудит) — подпись «что внутри этой сборки».

## 3. Бизнес-контекст

NFR-10: версии шкал/модели фиксируются в релизе и видны пользователю — release notes публичная половина этого требования (вторая — «О приложении», TASK-100). Для медицински-чувствительного продукта история «что изменилось» — часть доверия.

## 4. Технический контекст

- **Архитектура:** релизный процесс — арх. 10 §3; draft создаётся пайплайном (105) с автогенерированным changelog — шаблон дополняет структурой.
- **Обоснование:** обязательные строки версий — чек-лист в шаблоне: пропустить сложно (пустые `{{}}`-плейсхолдеры видны).

## 5. Объём

- **Включено:** шаблон: `## Что нового` / `## Исправлено` / `## Версии внутри` (приложение {{app}}, схема БД {{schema}}, шкала {{scale}}, модель {{model|«ИИ не входит»}}) / `## Известные проблемы` / `## Проверки` (ссылки: сетевой аудит {{audit}}, perf-отчёт {{perf}}, DoD {{dod}}) / `## Обновление` (инструкция для пользователя: авто-обновление/ручное) / дисклеймер-строка (продукт не медсовет — каждая версия); пайплайн 105 уже заливает заготовку — сверка соответствия шаблону; процесс-док: раздел «Релиз» в CONTRIBUTING (дополнение): шаги после draft: заполнить версии из «О приложении» сборки, приложить отчёты, прогнать NVDA/аудит-чеклисты, опубликовать, удалить rc-теги; reminder-строка о продлении сертификата (календарная — TD-замечание 104).
- **Не включено:** автозаполнение из commit-сообщений сверх changelog-генератора (ручная редактура — решение: пользовательские notes ≠ сырой git-лог).
- **Будущая работа:** EN-версия notes (пост-MVP).

## 6. Файлы

- **Создать:** `.github/release-template.md`; раздел в CONTRIBUTING; пример заполненных notes из rc-прогона 105 (`docs/release/notes-example.md`).
- **Изменить:** `release.yml` (использование шаблона при создании draft — если ещё не), CONTRIBUTING.
