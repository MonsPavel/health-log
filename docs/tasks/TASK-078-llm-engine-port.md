## 2. Цель

Application-порт `LlmEngine` (load/unload/complete-stream/cancel/status) + `FakeLlmEngine`: детерминированный генератор текста-токенов для юнит-тестов guardrails/резюме/чата и dev-режима E2E (env `HL_FAKE_LLM=1` — фиксированный TD-IMP реестра).

## 3. Бизнес-контекст

Guardrails и оркестрация обязаны тестироваться без модели — миллисекунды, без сети, детерминировано (арх. 10 §1). Fake-движок также даёт стабильные e2e-сценарии ИИ-экранов (TASK-088/090) без 2–3 ГБ модели в CI.

## 4. Технический контекст

- **Архитектура:** порты application — арх. 02 §5; адаптеры — real (процесс 076) и fake.
- **Обоснование:** fake на уровне порта (не мок jest.fn): поведение как у реального (стрим, отмена, ошибка) — тесты ценности, не имплементации. Dev-флаг `HL_FAKE_LLM=1` заставляет контейнер использовать fake вместо процесса — e2e без модели (запись в PM-док TD-реестр уже есть).

## 5. Объём

- **Включено:** порт `LlmEngine {ensureModel(modelId): Promise<void>; complete(req: {messages; params; signal}): AsyncIterable<{delta} | {done: finishReason}>; cancel(): void; status(): EngineStatus}`; адаптеры: `ProcessLlmEngine` (обёртка клиента 076 — тонкая), `FakeLlmEngine`: детерминированный сценарный генератор — ответы по ключевым словам запроса (фикстура-таблица: «среднее» → текст-резюме из констант; иначе — безопасный нейтральный текст), стрим по словам с микро-задержкой (configurable 0 в тестах), поддерживает abort; контейнер: выбор движка (env HL_FAKE_LLM → fake, лог «fake LLM активен» — предупреждение в UI? нет: только лог + строка «FAKE» в «О приложении» при флаге); тесты порта на fake.
- **Не включено:** спек-симуляцию guardrail-отказов в fake (отказы — домен 086, вне движка).
- **Будущая работа:** сценарный fake для eval-регрессий (расширение таблицы ответов).

## 6. Файлы

## 13. Бизнес-логика

Abort-семантика: signal.aborted → done(cancelled) — единообразие с реальным; BUSY-поведение fake имитирует (вторая генерация до завершения → AI/BUSY) — тесты оркестрации честны.

## 14. Безопасность

Fake не пишет в БД/сеть; env-флаг игнорируется в packaged (как HL_BENCH — тот же паттерн).

## 15. Производительность

Fake: 1000 токенов при задержке 0 — <50 мс (тест).
