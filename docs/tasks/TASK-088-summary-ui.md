## 2. Цель

Экран «ИИ» (вкладка «Разбор»): выбор периода, превью передаваемых данных с тумблером заметок (FR-5.5), кнопка «Объяснить мой период», стрим-текст по токенам, «Стоп»/«Повторить», кэш-подсказка, бейдж «данные изменились», несъёмный дисклеймер и период; отказ-ответы стилем «системного сообщения»; кнопка «Очистить разборы».

## 3. Бизнес-контекст

US-18/US-22: прозрачность «что увидит ИИ» — фундамент доверия к локальному анализу; честный дисклеймер (FR-5.6) — несъёмный элемент каждого ответа (AC-5.2). Пустые состояния обучают (модель не настроена → карточка-ссылка на TASK-081).

## 4. Технический контекст

- **Архитектура:** арх. 06 (feature ai); каналы 087.
- **Обоснование:** превью — вызов `ai/context/preview` (TASK-083) с текущими опциями: пользователь видит точный текст, который уйдёт в модель (не абстрактное «ваши данные»).

## 5. Объём

- **Включено:** `InsightScreen`: период-контрол (7/30/90/custom — общий паттерн); блок «Что передаётся ИИ»: текст preview (моноширинный, свёрнут до 10 строк с «показать всё»), тумблер «включить заметки» (prefs.aiSettings.includeNotes — событие обновляет preview); карточка-состояние модели: не настроена → CTA на вкладку «Модель» (TASK-081); генерация: кнопка «Объяснить период» → requestId → стрим-текст (авто-скролл, стоп-кнопка «Стоп»), финал: сохранён (тост)/кэш (бейдж «из кэша»)/отказ-стиль; стейлс: при latest.stale — бейдж «Данные изменились — обновите разбор» над текстом; дисклеймер-футер несъёмный + «Период анализа: …»; «Стоп» → cancel; «Повторить» → новый generate; «Очистить разборы» (advancedMode? нет — видимая, с подтверждением) → deleteAll; состояния ошибки (BUSY «генерация уже идёт», WORKER_CRASHED с повтором); тесты; e2e на fake-LLM.
- **Не включено:** markdown-рендер (текст как есть, pre-wrap — решение: без md-парсера в MVP), история резюме-список (последнее по периоду — достаточно).
- **Будущая работа:** экспорт резюме в PDF (068-опция уже ждёт — связка позже: выбор резюме на экране отчёта).

## 10. Фронтенд

Стрим-поведение: авто-скролл вниз, если пользователь у низа (не дёргать при ручном скролле вверх); «Стоп» виден только во время генерации; после done — «Повторить»; отказ-текст — серый блок с иконкой info (стильное различение от обычного разбора); stale-бейдж — жёлтый, клик = перегенерация.

## 11. API

Потребляет: `ai/context/preview`, `ai/summary/generate|result|latest`, `ai/cancel`, события ai:token/status.

## 12. Управление состоянием

Локальный state стрима (delta-append); кэш `['summary-latest', period]`; инвалидация по финалу генерации и measurement:changed (обновить stale-бейдж — refetch latest).

## 13. Бизнес-логика

Гонки: смена периода во время генерации → авто-cancel текущей (решение); уход с экрана во время генерации → cancel (useEffect-cleanup); BUSY — тост-подсказка.
