## 2. Цель

Осмысленные состояния экрана динамики при отсутствии/дефиците данных: пустой период → обучающая заглушка с CTA «Добавить измерение»; мало данных → график показывается с пометкой «мало данных» (не «пустое полотно», AC-3.6, FR-3.6).

## 3. Бизнес-контекст

Первые дни использования — самые частые пустые экраны (FR-9.2): пустота без подсказки = впечатление «сломано». EC-09-дух: честно говорить «данных мало», не строить выводы.

## 4. Технический контекст

- **Архитектура:** FR-3.6, AC-3.6, EC-09; данные — trend/series (points.length) и stats.insufficientData.
- **Обоснование:** состояния определяются из уже загруженных данных (trend+stats), без дополнительных запросов.

## 5. Объём

- **Включено:** `EmptyChartState` (нет точек в периоде): иконка, текст «За выбранный период измерений нет», CTA «Добавить измерение» → форма; текст-альтернатива при записях вне периода («Есть записи раньше — покажите всё» → период=all, только если total>0 — известен из stats? требуемый источник: `['measurements']`-мета? УПРОЩЕНИЕ: без второго запроса — показывать оба действия: «Добавить» и «Показать все время»); `FewDataNote` (точки 1–6): полоса над графиком «Мало данных — {N} измерений за период. Выводы будут точнее с накоплением» + график рендерится; интеграция в DashboardScreen (ветвление по trend/stats); тесты.
- **Не включено:** различение «нет данных вообще» vs «вне периода» через доп. запрос (упрощение §5), онбординг-обход (P1-фаза уже прошла).
- **Будущая работа:** обучающие квесты «первая неделя» (пост-MVP).
