## 2. Цель

Экран «Приватность» (в настройках): перечень всех возможных сетевых операций приложения (из политики) с переключателями согласий и человекочитаемым описанием «зачем», живая лента последних сетевых активностей (когда/что/статус/объём), публичная формулировка обещания приватности.

## 3. Бизнес-контекст

US-33 + BG-2: проверяемая честность — конкурентное преимущество продукта; экран — то, что покажет пользователь (или П2 со сниффером): журнал должен совпадать с наблюдаемым трафиком (AC-4.1-витрина).

## 4. Технический контекст

- **Архитектура:** каналы 098; события — 075.
- **Обоснование:** лента live (не по кнопке «обновить»): пользователь запускает загрузку модели в соседней вкладке и ВИДИТ запись мгновенно — эффект доверия.

## 5. Объём

- **Включено:** `PrivacyScreen` (секция настроек): (1) обещание-шапка: «Ваши данные обрабатываются только на этом компьютере. Ниже — все случаи, когда приложение может выйти в сеть»; (2) список операций: название, описание «зачем» (descriptionKey), переключатель согласия (мгновенное применение, confirm при отключении «загрузка моделей станет недоступна»); (3) лента активностей: строки (дата-время Intl, название операции, статус ok/blocked/failed цвет+иконка не-только-цветом, объём КБ/МБ), empty «Сетевых активностей не было»; (4) ссылка-пояснение «Как проверить самостоятельно?» — раскрывающийся блок с инструкцией (мониторинг соединений ОС) — честность-паттерн; тесты.
- **Не включено:** очистку журнала вручную (ротация TASK-103), детальные логи запросов.
- **Будущая работа:** экспорт журнала (диагпакет 103 покрывает).

## 10. Фронтенд

Переключатель согласия: optimistic + откат при ошибке; disabled-состояние объясняется (модель скачивается — переключение заблокировано с tooltip «идёт загрузка»).

## 11. API

`privacy/journal`, `privacy/consents`; события net:activity.

## 12. Управление состоянием

useQuery 098-ключи; консенты-мутация через тот же канал.

## 13. Бизнес-логика

Статусы ленты: ok (зелёная галочка), blocked (серая «запрещено»), failed (красная «ошибка») — иконки различны (дальтонизм). Отключение modelsDownload при активной загрузке — переключатель заблокирован до конца загрузки (согласование с ModelStore — подписка на состояние).

## 14. Безопасность

Инструкция самопроверки — не скрытый уговор: конкретные шаги для Windows (Resource Monitor) — документируется и тестируется на наличие.

## 15. Производительность

Лента ≤50 записей — мгновенно.

## 16. Доступность

Переключатели — switch-паттерн aria-checked; статусы — aria-label полные; live-лента aria-live polite; контраст AA.

## 17. Интернационализация

## 19. Стратегия тестирования
