## 2. Цель

Скелет интерфейса: HashRouter с пятью маршрутами-заглушками, Sidebar-layout, система тем (light/dark/system) на CSS-переменных с rem-токенами трёх размеров текста, react-i18next с каталогом `ru` и скриптом проверки ключей, утилита форматирования дат через Intl.

## 3. Бизнес-контекст

Два решения задаются до первой фичи, потому что ретрофит дороже фичи: (1) все тексты — только ключи i18n (литералы в JSX размножаются лавиной — TD-4); (2) размеры текста — в rem-токенах, иначе «очень крупный режим» П3 (FR-8.2, NFR-6) потребует переверстки. Навигация фиксирует информационную архитектуру продукта: Динамика · Журнал · ИИ · Отчёты · Настройки.

## 4. Технический контекст

- **Архитектура:** структура рендерера — `docs/architecture/06-frontend.md` §2; темы/крупный текст — §7; состояния — §3 (создаётся QueryClient-провайдер здесь).
- **Пакеты:** `apps/desktop` (renderer); зависимости: react-router-dom, react-i18next, i18next, @tanstack/react-query, tailwindcss.
- **Обоснование:** HashRouter — совместим с file://-подобной загрузкой prod-сборки (арх. 06 §4). Токены — CSS-переменные (не JS-константы): тема и масштаб применяются без ре-рендера дерева.

## 5. Объём

- **Включено:** layout (Sidebar 240px + content, сворачивание — нет в MVP); маршруты: `/dashboard`, `/journal`, `/ai`, `/reports`, `/settings` — экраны-заглушки с i18n-заголовками и обучающим пустым текстом «Экран появится после настройки» (ключ `common.wip`); ThemeProvider: `data-theme="light|dark"` на `<html>`, режим system через matchMedia, выбор сохраняется в localStorage (позже мигрирует в prefs — TASK-047, ключи совместимы); токены: цвета фона/текста/акцента/границы для обеих тем (значения — Tailwind slate-палитра как база, контраст AA на паре текст/фон), `font-size: 100/112.5/125%` классы на `<html>` (обычный/крупный/очень крупный, FR-8.2); react-i18next: init (ru default, fallback ru), каталог `src-renderer/i18n/ru/{common,errors}.json` (common: названия разделов, wip; errors: internal, validation, renderer — согласованы с TASK-008/011), скрипт `check:i18n` — сравнение используемых ключей с каталогом (grep-based, TD-IMP-2); QueryClientProvider (defaultOptions: retry 0 — локальные операции мгновенны, staleTime Infinity — инвалидация событиями, арх. 06 §3); утилита `formatDateTime(instantLike, locale, preset)` через Intl.
- **Не включено:** дизайн-система компонентов (кнопки/поля — появляются с фичами, TASK-031), переключатель размера текста в настройках (TASK-047), полный каталог ошибок (пополается по мере задач).
- **Будущая работа:** второй каталог `en` (пост-MVP, TD-4).

## 12. Управление состоянием

QueryClient: `defaultOptions.queries.retry: 0, staleTime: Infinity, gcTime: 10 мин` — обоснование: локальные операции либо мгновенны (retry не нужен), либо ошибка — результат валидации; инвалидация — только событиями (TASK-009). Тема — localStorage `hl.theme` (`system|light|dark`), размер текста `hl.textScale` (`100|112.5|125`) — ключи зарезервированы для миграции в prefs (TASK-047).

## 13. Бизнес-логика

Тема: mode system → подписка matchMedia('(prefers-color-scheme: dark)'), живое переключение без перезагрузки. Размер текста: класс на `<html>` до первого рендера (inline-скрипт в index.html читает localStorage — защита от FOUC); переключение позже — без перезапуска.

## 14. Безопасность

localStorage не хранит ничего чувствительного (только тема/масштаб) — политика: никаких данных пользователя в localStorage (проверка ревью); CSP уже задан (TASK-008).

## 15. Производительность

React.lazy для каждого маршрута (код-сплит с первого дня); начальный бандл рендерера ≤300 КБ gzip (замер vite build — вывод размера в консоль); Sidebar не ре-рендерится при смене маршрута (layout вне Routes).

## 16. Доступность

Семантика: `<nav>`, `<main>`, `aria-current`; контраст пар текст/фон обеих тем ≥4.5:1 (проверка контраст-скриптом на токенах — простой расчёт WCAG в тесте); фокус-стили: видимый outline на интерактивных (заглушки ссылок); клавиатура: Tab-порядок Sidebar → content (родной); reduced-motion: анимации только через `motion-safe:` (нет анимаций в P0 — правило на будущее в комментарии токенов).

## 17. Интернационализация

Каталог `ru` — источник истины; скрипт check:i18n: извлекает `t('…')`-ключи из src-renderer, сравнивает с ru/*.json — отсутствие ключа или неиспользуемый ключ = ошибка (выполняется в CI с TASK-014). ICU-плюрализация — с первого использования счётчиков (ключей со счётчиками пока нет).
