## 2. Цель

Секция «Обновления» в настройках: статус (версия, последняя проверка), кнопка «Проверить обновления» (уважает согласие), при доступной версии — «Скачать» с прогрессом и «Установить и перезапустить»; заготовка переключателя канала (stable/beta — активируется в TASK-107).

## 3. Бизнес-контекст

Управление обновлениями — в руках пользователя: проверять/качать/ставить — только явными действиями (D15); состояние прозрачно (когда проверяли, что нашли).

## 4. Технический контекст

- **Архитектура:** арх. 09 §5 (канал beta — роль постепенного включения фич).
- **Обоснование:** секция в «Настройках» (не модальные попапы): предсказуемое место; событие update:available — бейдж на секции.
