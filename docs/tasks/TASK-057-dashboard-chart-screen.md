## 2. Цель

Экран «Динамика» (/dashboard): линейный график СДА/ДДА по времени, опорные линии справочных значений с подписью источника шкалы, точки различают утро/вечер (форма+цвет, не только цвет), переключатели периода 7д/30д/90д/всё/произвольный (URL), тултип с точными значениями и переходом к правке записи.

## 3. Бизнес-контекст

US-10/US-11: главный экран понимания «что происходит». Врач (П5) первым делом смотрит динамику к опорным линиям; П1 — «не взлетает ли». Позиция: после read models и ADR — экран только собирает готовые данные.

## 4. Технический контекст

- **Архитектура:** экран — арх. 06 §8; данные — trend/series (056), шкала — scales/active (051).
- **Пакет:** renderer feature `dashboard`; библиотека — победитель ADR-0003 (TASK-055).
- **Обоснование:** периоды на экране — те же URL-семантики фильтров (TASK-044/046): один паттерн period по продукту (перенос `filters.ts`-утилит в общий lib — включено).

## 5. Объём

- **Включено:** `DashboardScreen`: период-контрол (7/30/90/all/custom — переиспользование TASK-044/046), выборка trend/series и scales/active; график: две линии sys/dia (цвета из токенов, различимые при дальтонизме: сплошная/пунктир или маркеры-формы), опорные линии границ «высокое нормальное»/«АГ1» (140/90 и 130/85 — из данных шкалы, не хардкод: sys-порог high_normal и hypertension1) с подписью «ESC/ESH 2018» (sourceLabel); точки: morning=круг, evening=квадрат, other=треугольник (форма+цвет); режим daily: столбики-диапазоны (min-max «коридор») + линия avg; тултип: дата-время (Intl), значения, пульс, часть суток, кнопка/клик → открытие правки записи (TASK-038 edit-режим); легенда (sys/dia/утро/вечер); empty/скелетон — TASK-060 (каркас места оставлен); URL `?period=`; тесты.
- **Не включено:** ЧСС-вид (058), таблица (059), empty-детали (060), сглаживание.
- **Будущая работа:** zoom, экспорт изображения (PDF-задача решает самостоятельным рендером).

## 12. Управление состоянием

## 13. Бизнес-логика

Опорные линии: только sys-пороги на sys-графике (dia-график — dia-пороги); подпись источника — один раз на график (не на каждую линию). Пустые части суток в тултипе: 'other' — подпись «другое время». Пограничный: одна точка — маркер без линии (библиотечный нюанс — проверить в реализации).
