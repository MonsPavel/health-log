## 2. Цель

Пульс просматривается отдельно: переключатель «Давление / Пульс» на экране динамики; график ЧСС с опорным коридором 60–100 уд/мин (справка, не классификация) и подсветкой записей с флагом «неровный пульс» (EC-10).

## 3. Бизнес-контекст

ЧСС всегда измеряется тонометром и спрашивается врачом; смешивать единицы мм рт. ст. и уд/мин на одной оси нельзя (решение TASK-058 дорожной карты) — отдельный вид без дублирования данных.

## 4. Технический контекст

- **Архитектура:** тот же trend/series (056) — пульс уже в точках; никакого нового канала.
- **Обоснование:** вкладка вместо второго графика: один экран — один фокус; переключение мгновенно (данные в кэше одни).

## 5. Объём

- **Включено:** сегмент-переключатель «Давление/Пульс» на DashboardScreen (URL `?view=pulse`); PulseChart: точки ЧСС (raw: point, daily: avg+коридор), опорные линии 60 и 100 (константы PULSE_REF_LOW/HIGH с комментарием «справка, не классификация» — из контракта contracts/trends или константы пакета? РЕШЕНИЕ: константы в `@hl/contracts` рядом с trend-типами, комментарий-синхронизация); точки с pulse undefined — пропускаются (в статистике считаются отдельно — уже так); irregularPulse-записи: маркер-иконка на точке + tooltip «неровный пульс — значение может быть неточным» (EC-10); тултип/переход к правке — как давление; подпись единицы «уд/мин»; тесты.
- **Не включено:** классификацию пульса (tachycardia-метки — не делаем, только коридор-справка), сравнение давление+пульс на одном экране (post-MVP overlay).
- **Будущая работа:** процент точек вне коридора (мини-статистика) — post-MVP.
