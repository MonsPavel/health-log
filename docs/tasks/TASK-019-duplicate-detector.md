## 2. Цель

Чистая функция `detectDuplicate(recentMeasurements, candidate) → flag`: те же sys/dia в пределах 2 минут от существующей записи — сигнал вероятного дубликата (EC-04).

## 3. Бизнес-контекст

Двойное сохранение (Enter дважды, забыл, что ввёл) размывает статистику без пользы. Бережная подсказка, как с опечатками: решение за пользователем (SRS 07 EC-04).

## 4. Технический контекст

- **Архитектура:** доменный сервис — арх. 02 §3.1.
- **Модуль:** `measurement/domain`.
- **Обоснование:** окно 2 минуты и совпадение обоих значений — минимальное правило с предсказуемым поведением; сравнение пульса не требуется (часто отличается между измерениями).

## 5. Объём

- **Включено:** `detectDuplicate(recent: ReadonlyArray<BpMeasurement>, candidate: {sys, dia, utcMs}): boolean` (true = вероятный дубль); константа `DUPLICATE_WINDOW_MS = 120_000`; тесты.
- **Не включено:** слияние/автоудаление дублей (никогда — данные пользователя священны); UI (TASK-032).
- **Будущая работа:** fuzzy-совпадение (±2 мм рт. ст.) — только при пользовательском спросе.

## 6. Файлы

- **Создать:** `apps/desktop/src/main/modules/measurement/domain/duplicate-detector.ts`, тесты; константа в `constants.ts`.

## 7. Модель предметной области

Сигнатура выше; правило: существует запись r из recent, где `r.bp.sys===candidate.sys && r.bp.dia===candidate.dia && abs(r.takenAt.utcMs − candidate.utcMs) ≤ 120_000`. recent — последние ~10 записей (передаёт use case; функция не фильтрует время сама — pure).

## 13. Бизнес-логика

Границы: ровно 120 000 мс → дубль (≤ включительно); 120 001 → нет. Одинаковые значения у разных рук — всё равно дубль-кандидат (решение: правило по значениям, рука игнорируется — задокументировать). Ночная запись и утренняя «такая же» через 8 часов — не дубль (окно).

## 19. Стратегия тестирования

Юнит-тесты: граничные 120 000/120 001 мс; совпадение только dia → false; совпадение sys→ dia другое → false; пустой recent → false; рука left/right с одинаковыми значениями → true (задокументированное решение).

## 20. Критерии приёмки

- [ ] Те же значения, Δ=119 с → true; Δ=121 с → false; Δ=120 с ровно → true.
- [ ] Только sys совпал → false.
- [ ] Пустая история → false.
- [ ] Константа 120_000 — единственный литерал окна.
