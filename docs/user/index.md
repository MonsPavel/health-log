# Руководство пользователя Health Log

Локальный дневник артериального давления: ваши измерения живут только на вашем
компьютере и работают без интернета.

**Тон этого руководства** — мы держим несколько обещаний:

- дружелюбно и без паники;
- без медицинских обещаний: дневник записывает и показывает, но **не является
  медицинской консультацией**;
- шаги пронумерованы — можно делать по порядку;
- каждая страница проверена на приложении «вручную», без отсылок «разберётесь».

## Три главных правила

1. **Измеряйте в одно и то же время** — утро и вечер лучше всего показывают
   картину; пропуски — это нормально, дневник не штрафует.
2. **Делайте копию раз в неделю** — меню «Отчёты → Данные → Создать копию»
   ([подробнее](data.md)). Придумайте для копии отдельный пароль и запишите его.
3. **Это не медицинский прибор.** Дневник помогает собрать данные для разговора
   с врачом, но **не является медицинской консультацией**. При значениях от
   180/120 и плохом самочувствии обратитесь за помощью ([что делать](faq.md)).
