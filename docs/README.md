## Система идентификаторов

- **П1–П5** — персоны; **US-xx** — истории; **FR-x.y** — функциональные требования; **NFR-x** — нефункциональные; **UC-xx** — сценарии; **EC-xx** — пограничные случаи; **AC-x** — критерии приёмки; **R-x / A-x / OQ-x** — риски / допущения / открытые вопросы.
- Истории ссылаются на FR и UC; критерии приёмки — на FR; объём MVP (док 10) сводит всё вместе.

## Глоссарий

- **АД** — артериальное давление; **СДА** — систолическое («верхнее»), мм рт. ст.; **ДДА** — диастолическое («нижнее»), мм рт. ст.; **ЧСС** — частота сердечных сокращений (пульс), уд/мин.
- **АГ** — артериальная гипертензия. **ESC/ESH** — Европейское кардиологическое общество / Европейское общество гипертонии (источник справочных шкал). **AHA** — Американская кардиологическая ассоциация.
- **LLM** — большая языковая модель. **«Локальный ИИ»** — инференс LLM на устройстве пользователя, без отправки данных на серверы.
- **Домашнее АД** — давление, измеренное бытовым тонометром вне клиники.
