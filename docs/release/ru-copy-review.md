# Ревизия RU-текстов (TASK-110, гейт релиза M-7.2)

> Сквозная ревизия i18n-каталогов RU и RU-констант main: запрет-лексика SRS 01 §8,
> обязательные дисклеймеры FR-5.6, единый спокойный тон, согласованность терминов,
> корректность params-подстановок. Инструмент — `tools/scripts/copy-audit.mjs`
> (`pnpm copy:audit`), шаг PR-пайплайна (после check:i18n, до typecheck).
> Дата: 2026-10-03. Ветка: `task/TASK-110`.

## 1. Методология (честно)

- **Автоматический проход**: скрипт `copy-audit` (юнит-тесты — 42) сканирует все
  RU-каталоги рендерера (7 файлов, 351 значение: `i18n/ru/*.json`,
  `features/*/ru.json`, `components/*/ru.json`) и 5 файлов RU-констант main
  (critical-texts 041/086, refusal-texts 086, system-prompt 084, generate-summary
  087, REPORT_RU 068) — только строковые литералы, комментарии не сканируются.
  Проверки: (1) запрет-корни §4 (whitelist-подход: находка гасится записью с
  причиной, §22); (2) обязательные подстроки §13 (таблица ключ→подстрока);
  (3) params-дрейф в обе стороны по 110 файлам использования t().
- **Ручной тон-обход**: чтение всех текстов девяти экранов по чек-листу тона
  (спокойствие, отсутствие императивов-паник, отсутствие вины — FR-4.4) и глоссарию
  `docs/terminology.md`. **Ограничение (честно)**: обход выполнен на уровне
  источников (каталоги + компоненты экранов), а не как скриншот-проход запущенного
  приложения с фикстурными данными — в автономной среде прогона GUI-сессия не
  воспроизводится; каждый ключ каталога и каждый компонентный текст прочитаны.
  Скриншот-проход остаётся за релизной ручной приёмкой (CONTRIBUTING §10).
- **Дополнительная проверка на «копию мимо каталога»**: скан кириллических
  литералов в коде рендерера вне комментариев — вне каталогов находятся только
  dev-сообщения хуков/IPC, единицы измерения (ГБ/МБ/КБ, мм рт. ст.), слово
  «скорая» из реестра служб (тест-сверка с main, 041) и тест-фикстуры. UI-копии
  мимо i18n нет.

## 3. Находки и правки

### 3.1 Дисклеймеры отклонялись от канона FR-5.6 (регуляторная находка)

SRS 01 §8 / FR-5.6 фиксируют формулировку «не является медицинской консультацией»,
фактические тексты использовали усечённую «Это не медицинская консультация» и в
PDF — «не является медицинским заключением». Все пять точек приведены к канону:

| Точка | Было | Стало |
|---|---|---|
| Экран «Разбор», подвал (`ai.insight.disclaimer`) | Это не медицинская консультация. | Это не является медицинской консультацией. |
| Константа 087 (`AI_SUMMARY_DISCLAIMER_TEXT`, поле `disclaimer_text` БД) | То же | То же (канон) |
| ИИ-маркировка PDF (`REPORT_RU.ai.disclaimer`) | Сгенерировано ИИ, не является медицинским заключением | Сгенерировано ИИ; не является медицинской консультацией |
| Подсказка чекбокса ИИ (`report.includeAi.tooltip`) | Резюме ИИ не является медицинским заключением… | Резюме ИИ не является медицинской консультацией… |
| System prompt, ОБЯЗАТЕЛЬНО (084) | …пометку: «Это не медицинская консультация» | …пометку: «Это не является медицинской консультацией» |

Сопровождение: правка текста system prompt → **PROMPT_TEMPLATE_VERSION 1→2**
(правило §13 084: contextHash 083 — кэш-резюме честно помечаются устаревшими,
FR-5.7); golden-снапшот `system-prompt-v2.txt`; синхронно обновлены тесты-сверки
(041/086/087, contracts, renderer-UI, e2e-спеки) — осознанный коммит.

### 3.2 Терминология

- Глоссарий создан: `docs/terminology.md` — СДА=«верхнее», ДДА=«нижнее» (подписи
  полей «Верхнее (СДА)»/«Нижнее (ДДА)»; в таблицах/агрегатах — сокращения;
  полные «Систолическое (СДА)» — только расшифровки легенд), «измерение»,
  «период», «разбор», «давление» без аббревиатуры «АД».
- **Находка-правка**: заголовок графика PDF «Динамика систолического **АД**» →
  «Динамика систолического **давления**» — единственное место с аббревиатурой
  «АД» в пользовательских текстах.
- Сверка по экранам: «измерение» единообразно (счётчики, фильтры, отчёты); «период»
  — в ИИ («Период анализа»), таблице, отчёте; «разбор» — имя вкладки/действий ИИ
  (историческое «резюме» осталось только в идентификаторах/БД — не UI).

### 3.3 Тон-обход: 9 экранов (чек-лист: спокойствие · без паник-императивов · без вины · FR-4.4)

| # | Экран (тексты) | Вердикт | Примечания |
|---|---|---|---|
| 1 | Сводка (/dashboard — dashboard.*, common.*) | PASS | «Пора сделать резервную копию…», «Начните сегодня — это просто», «Мало данных… выводы будут точнее с накоплением» — без вины; «Коридор 60–100 уд/мин — справка, не классификация» — регуляторная рамка |
| 2 | Журнал (/journal — measurement.*) | PASS | Диалоги-подтверждения фактичны («Действие необратимо»), опечатка-детектор без упрёка («проверьте, нет ли опечатки») |
| 3 | ИИ — Разбор (ai.insight.*) | PASS | Дисклеймер канон; «Данные изменились — обновите разбор» — нейтрально (FR-5.7) |

| 5 | ИИ — Модель (ai.models.*) | PASS | Согласие/отзыв, честные предупреждения ОЗУ/языка, «может работать медленно» без запугивания |
