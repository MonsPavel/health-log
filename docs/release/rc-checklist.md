### Процедура сборки RC (выполняет владелец)

1. Убедиться, что `main` зелёный и все предрелизные задачи смержены (раздел 9).
2. `git tag -a v1.0.0-rc.1 <sha main> && git push origin v1.0.0-rc.1` — пайплайн
   105 строит подписанный артефакт и создаёт draft (версия берётся из тега).
3. Draft опубликовать **как pre-release** (галка «Set as a pre-release»,
   CONTRIBUTING §11.1) — permalink «latest» не переезжает, stable-клиенты изолированы.
4. Сверить артефакт: `Get-AuthenticodeSignature <установщик>` → Status `Valid`;
   версия установщика = тегу; в assets есть `stable.yml` и `beta.yml` (§20-4 TASK-107).
5. Установить на машины A и B; зафиксировать фактическую версию в шапке прогона
   каждой машины ниже.
