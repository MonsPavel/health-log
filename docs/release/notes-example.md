> Health Log — локальный дневник давления для самонаблюдения. Приложение не
> является медицинским изделием и не является медицинской консультацией: не
> ставит диагнозов и не подбирает лечение. Показания измерений и разборы ИИ —
> материал для разговора с врачом, а не основание менять лечение самостоятельно.

## Что нового

- Дневник давления: ввод измерения за секунды, история и динамика с оценкой по справочной шкале ESC/ESH 2018.
- Разбор записей ИИ по желанию и локально: резюме периода простым языком — данные не покидают компьютер.
- Отчёты и перенос: PDF для врача, CSV-архив, автоматические копии с проверкой целостности.
- Бета-канал обновлений: новые версии можно пробовать раньше стабильных («Настройки → Обновления»).

## Обновление

- **Авто-обновление**: приложение предложит обновление само — «Настройки →
  Обновления → Проверить»; данные не затрагиваются.
- **Вручную**: скачайте из Assets этой страницы установщик
  «Health Log Setup 0.9.0-rc.0.exe» и установите поверх прежней версии —
  удалять или переустанавливать ничего не нужно.
