# Фаза P2 — Полнота журнала

**Веха фазы:** журнал полностью управляем (правка/удаление/фильтры/поиск), данные защищены эвристиками, настройки и крупный режим работают. Всё ещё без аналитики — фаза узкая и быстрая.

---

## Epic 2.1 — CRUD до конца

**T-2.1.1 (M) Use cases Update/Delete + хендлеры**
- **Цель:** правка любой записи (все поля), удаление; мутации поднимают data_version.
- **Почему:** US-2/US-8; доверие = «ошибку можно исправить».
- **Объём:** use cases, contracts-каналы, unit-тесты веток (правка после флагов — флаги пересчитываются).
- **Зависимости:** P1.3.
- **Файлы:** `src/modules/measurement/application/{update,delete}*`, `packages/contracts/src/measurement*`.
- **Проверка:** юнит + интеграционные тесты.
- **AC:** правка/удаление атомарны; data_version растёт; несуществующий id → `MEASUREMENT/NOT_FOUND`.
- **Риски:** нет.
- **Сложность:** M (1–2 ч)

**T-2.1.2 (M) UI: редактирование и удаление с подтверждением**
- **Цель:** правка через переиспользование формы ввода; удаление — подтверждение «необратимо» (FR-2.3).
- **Зависимости:** T-2.1.1, T-1.3.6.
- **Файлы:** `src-renderer/features/measurement/ui/*`.
- **Проверка:** e2e: создать → править → удалить.
- **AC:** после правки список и флаги актуальны; отмена удаления сохраняет запись (AC-2.2).
- **Риски:** нет.
- **Сложность:** M (1–2 ч)

**T-2.1.3 (S) Черновик ввода: восстановление после краша**
- **Цель:** незаполненная форма переживает перезапуск (NFR-3) — zustand persist черновика.
- **Зависимости:** T-1.3.4.
- **Файлы:** `src-renderer/features/measurement/model/draft*`.
- **Проверка:** заполнить → перезапустить → значения на месте.
- **AC:** черновик восстанавливается; очищается после успешного сохранения.
- **Риски:** нет.
- **Сложность:** S (0,5–1 ч)

**T-2.1.4 (S) Умная вставка «120/80» (Could из FR-1.4)**
- **Цель:** парсинг строки из буфера в оба поля; мусор — мягкая ошибка без потери введённого (EC-18).
- **Зависимости:** T-1.3.4.
- **Файлы:** `src-renderer/features/measurement/ui/form*`.
- **Проверка:** юнит-тесты парсера (разделители, мусор, «120, 80»).
- **AC:** «120/80» заполняет оба поля; «не помню» → понятная ошибка, поля не тронуты.
- **Риски:** нет.
- **Сложность:** S (0,5–1 ч)

## Epic 2.2 — Барьеры качества данных в интерфейсе

**T-2.2.1 (M) Панель критических значений (FR-7.4)**
- **Цель:** полноценная панель после сохранения критического измерения: текст SRS, симптомы, локальные номера экстренных служб; без диагнозов, без блокировки.
- **Почему:** duty-of-care; US-20; AC-6.
- **Объём:** компонент + реестр номеров по локали + каталог текстов.
- **Зависимости:** T-1.3.5.
- **Файлы:** `src-renderer/components/critical-panel*`, `src-renderer/i18n/ru/*`.
- **Проверка:** сверка текста с AC-6.1/6.2; ревизия тона.
- **AC:** панель по 190/125; конкретный следующий шаг; не блокирует работу.
- **Риски:** формулировки — сверка с докой SRS 01 §8 (запрет лексики).
- **Сложность:** M (1–2 ч)

**T-2.2.2 (M) Флаги в журнале и легенда**
- **Цель:** видимые маркеры записей: вероятная опечатка, неровный пульс, критическое значение; расшифровка легендой.
- **Зависимости:** T-1.3.6.
- **Файлы:** `src-renderer/features/measurement/ui/history*`.
- **Проверка:** скриншот-тесты состояний.
- **AC:** каждая запись с флагом различима и объяснима; EC-10 поддержан (флаг аритмии видно).
- **Риски:** визуальный шум — бейджи компактные.
- **Сложность:** M (1–2 ч)

**T-2.2.3 (S) E2E пограничных вводов (EC-01–04)**
- **Цель:** автопрогон сценариев: sys≤dia, экстремумы+подтверждение, дубль, опечатка.
- **Зависимости:** T-2.1.2, T-2.2.1.
- **Файлы:** `apps/desktop/tests/e2e/*`.
- **AC:** все сценарии зелёные в e2e; AC-1.2/1.3/1.4 покрыты.
- **Риски:** нет.
- **Сложность:** S (0,5–1 ч)

## Epic 2.3 — Фильтры и поиск

**T-2.3.1 (M) Фильтры списка**
- **Цель:** пресеты периодов (7/30/90/всё), фильтр руки и наличия заметки (FR-2.2); состояние фильтров — в URL.
- **Зависимости:** T-1.3.3, T-2.1.2.
- **Файлы:** list use case (расширение), `src-renderer/features/measurement/ui/filters*`.
- **Проверка:** интеграционные тесты фильтров + ручной прогон.
- **AC:** комбинации фильтров дают ожидаемые выборки (AC-2.1).
- **Риски:** нет.
- **Сложность:** M (1–2 ч)

**T-2.3.2 (M) FTS-поиск по заметкам**
- **Цель:** миграция v2 (fts5 + триггеры), канал `notes/search`, UI-строка поиска.
- **Почему:** US-9; поиск «после кофе» у П2.
- **Зависимости:** T-1.2.3.
- **Файлы:** `src/main/shared/db/migrations/v2*`, `src/modules/measurement/adapters/fts*`, renderer search.
- **Заметки:** русский поиск fts5 без стемминга — substring-fallback; решение зафиксировать в коде-комментарии.
- **Проверка:** интеграционные тесты индексации (вставка/правка/удаление синхронизируют FTS).
- **AC:** поиск находит по подстроке; правка/удаление не оставляют «призраков» в выдаче.
- **Риски:** ограничения fts5 для морфологии — принять, задокументировать.
- **Сложность:** M (1,5–2,5 ч)

**T-2.3.3 (S) Произвольный период**
- **Цель:** date-range picker для фильтров (основа для отчётов P4).
- **Зависимости:** T-2.3.1.
- **Файлы:** `src-renderer/components/date-range*`.
- **AC:** выбор диапазона фильтрует список и сохраняется в URL.
- **Риски:** нет.
- **Сложность:** S (0,5–1 ч)

## Epic 2.4 — Настройки и персонализация

**T-2.4.1 (M) Хранилище настроек + экран настроек**
- **Цель:** app_setting (prefs) + use cases get/set + каналы; экран: тема, размер текста, формат даты (FR-8.1/8.2/8.4).
- **Зависимости:** T-1.2.6.
- **Файлы:** `src/main/modules/settings-profile/*`, `src-renderer/features/settings/*`.
- **Проверка:** интеграционные тесты (set → перезапуск → применилось).
- **AC:** настройки персистентны; применение мгновенно без перезапуска.
- **Риски:** валидация prefs — zod-схема при чтении (повреждённые настройки → дефолты + лог).
- **Сложность:** M (1,5–2,5 ч)

**T-2.4.2 (M) Крупный режим (AC-7.2)**
- **Цель:** три размера текста на rem-токенах; скриншот-тесты основных экранов в «очень крупном».
- **Почему:** персона П3 — полноправная, NFR-6.
- **Зависимости:** T-2.4.1.
- **Файлы:** `src-renderer/tokens*`, e2e-snapshots.
- **Проверка:** e2e-снапшоты экранов на каждом размере.
- **AC:** ничего не обрезается/перекрывается на любом размере; AC-7.2 зелёный.
- **Риски:** фиксированные высоты в компонентах — ревизия при обнаружении.
- **Сложность:** M (1–2 ч)

**T-2.4.3 (S) Простой/продвинутый режим (FR-9.3)**
- **Цель:** simpleMode по умолчанию: продвинутые настройки скрыты; переключатель.
- **Зависимости:** T-2.4.1.
- **Файлы:** settings UI, флаг из реестра флагов (09 §4).
- **AC:** в простом режиме видны только базовые настройки; продвинутый открывает всё.
- **Риски:** нет.
- **Сложность:** S (0,5–1 ч)

**Веха P2:** журнал — «дом для данных»: полный CRUD, фильтры, поиск, защита от опечаток; настройки и крупный режим работают; e2e-набор журнала зелёный.
